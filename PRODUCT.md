## Platform

web

## Users

- **Репетитор (владелец, один человек).** Частный преподаватель информатики, готовит к ЕГЭ (КЕГЭ). Работает с компьютера и с телефона: между занятиями и сразу после них отмечает занятие, пишет отчёт, вносит оплату, выдаёт ДЗ. Других репетиторов и общей админки нет.
- **Ученики 10–11 класса и их родители.** Заходят в основном с телефона. Видят только свой кабинет (только чтение): расписание, прогресс по темам, оценки, ДЗ, баланс и — после этой доработки — материалы к прошедшим занятиям.

## Product Purpose

Один инструмент вместо таблиц и мессенджеров: ученики, расписание, программа курса ЕГЭ по информатике, контроль знаний, ДЗ, оплаты и абонементы, отчёты родителям. Успех — репетитор тратит минуты на учёт после занятия, а ученик и родитель всегда видят актуальную картину без расспросов.

## Positioning

Кабинет собран вокруг конкретного годового курса ЕГЭ по информатике: 77 тем в порядке прохождения, контрольные точки (обязательные и дополнительные симуляции, проверочные и контрольные работы), перевод первичных баллов КЕГЭ во вторичные, слабые темы по результатам. Это не универсальная CRM для репетиторов.

## Operating Context

- Занятия онлайн и очно, регулярные (еженедельные серии) и разовые.
- После занятия: отметка статуса, отчёт (темы, что прошли, что задано, оценка), автосоздание ДЗ, списание с баланса/абонемента.
- **Новое:** после занятия репетитор прикладывает материалы для повторения — файлы с кодом (.py и др.), PDF и презентации, ссылки. Ученик открывает их из своего кабинета с телефона.
- Родителям отправляется текстовый отчёт в мессенджер или PDF.

## Capabilities and Constraints

- Next.js 15 (App Router, статический экспорт), React 19, TypeScript, Tailwind CSS 3.
- Хостинг: GitHub Pages (`https://3-tonn.github.io/tutor-cabinet/`), автодеплой через GitHub Actions.
- Данные: Supabase (Postgres + RLS + Storage, бакет `files`); без ключей — демо-режим в localStorage.
- Роли: репетитор (таблица `tutors`), ученик/родитель (e-mail в карточке ученика), «нет доступа».
- Интерфейс полностью на русском: ₽, ДД.ММ.ГГГГ, неделя с понедельника.
- Светлая и тёмная тема обязательны.

## Brand Commitments

- Название: «Кабинет репетитора», подпись «ЕГЭ по информатике».
- Пожелание владельца: интерфейс должен выглядеть технологично, в духе информатики и программирования.

## Evidence on Hand

- Учебный план курса: `src/lib/ege-informatics.ts` (из расписания владельца).
- Демо-данные генерируются (`src/lib/demo.ts`) — это не реальные ученики; отзывов, статистики и логотипа нет, их нельзя выдумывать.

## Product Principles

1. Учёт после занятия — за минуту, с телефона.
2. Ученик и родитель видят только своё и только для чтения; доступ проверяет база, а не интерфейс.
3. Всё строится вокруг курса ЕГЭ по информатике: темы, контрольные точки, баллы КЕГЭ.
4. Числа (время, деньги, баллы) — главная информация на экране.

## Accessibility & Inclusion

Основное устройство учеников — телефон: крупные цели нажатия, читаемый текст, работа в светлой и тёмной теме. Уровень WCAG 2.2 AA как ориентир.
